# FizzBuzz Problem

This project provides a solution to the FizzBuzz text replacement problem.

The implementation focuses on clean, readable, and maintainable code. To achieve this, I applied the **Single Responsibility Principle (SRP)**, one of the **SOLID principles**, by separating validation, replacement logic, and text processing into dedicated methods.

## Features

- Replaces every third word with **Fizz**
- Replaces every fifth word with **Buzz**
- Replaces every fifteenth word with **FizzBuzz**
- Preserves whitespace and punctuation
- Counts the total number of replacements
- Includes XML documentation for public members
- Follows clean code and C# coding conventions
